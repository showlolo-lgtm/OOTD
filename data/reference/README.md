Place one preset reference portrait here for the demo try-on flow.

Supported file names:
- `model-reference.jpg`
- `model-reference.jpeg`
- `model-reference.png`
- `reference.jpg`
- `reference.jpeg`
- `reference.png`

The backend will use this file automatically when `OOTD_MODEL_REFERENCE_IMAGE_PATH` is not set.
The iOS build script will also bundle the same file into the app resources.
